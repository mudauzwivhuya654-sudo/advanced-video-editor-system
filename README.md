# advanced-video-editor-system
Java console application for managing video editing projects, pricing, and client reports.

## Features

- Login authentication
- Client information capture
- Video type selection
- Budget calculation
- Student discount handling
- Urgent project fees
- Premium and Standard project classification
- Final project reporting

## Technologies

- Java
- Scanner
- Conditional Statements
- Nested If Statements
- printf Formatting
